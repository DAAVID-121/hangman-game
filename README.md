# One of my first projects I wrote: Hangman

A simple word guessing game written in Python.

The program picks a random word, and you guess it letter by letter before you run out of lives.

## Features

- Random word chosen from a list
- 6 lives
- Guessed letters are shown in place, the rest as underscores
- Shows lives left and letters already tried
- Input validation (only a single letter, no repeated letters)
- Option to play again

## How to run?

1. Install Python 3
2. Download `hangman.py`
3. Run in a terminal:

```
python hangman.py
```

## What I learned?

- Loops (`while`, `for`)
- Lists and strings
- The "random" module
- Input validation
